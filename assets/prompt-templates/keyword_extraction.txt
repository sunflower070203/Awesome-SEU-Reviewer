你的任务是从给定的课程材料中提取关键知识点和考点。

输入：
- PPT 文本（按章节组织）
- 往年真题（按年份组织）
- 学生复习笔记（可选）

输出要求：
1. 列出 Top 20 关键词，按权重降序
2. 每个关键词需说明来源（"PPT:ch3.pptx (N次)" / "真题:2023 (M次)"）
3. 标注近 3 年的趋势（stable / increasing / decreasing）

输出格式（严格 JSON）：
```json
{
  "keywords": [
    {
      "term": "中心极限定理",
      "weight": 0.92,
      "source": "PPT:ch3.pptx (12次) + 真题:2023 (3次)",
      "first_seen": "2023_final",
      "recency_trend": "stable"
    }
  ]
}
```

注意事项：
- 不包含"题目"、"答案"等通用词
- 优先包含学科专有名词、定理名、公式
- 区分概念词（如"正态分布"）和公式词（如"$X \\sim N(\\mu, \\sigma^2)$"）
- 公式词单独列出，权重略高于概念词
