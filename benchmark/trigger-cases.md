# 触发效果测试用例

> 目的：检验各 Agent **是否在正确的时机自动触发**本技能，以及触发后是否走对了分支。
> 每条用例只发那一句话（可带附件），观察 Agent 的反应。

## 判定标准

| 结果 | 含义 |
|---|---|
| ✅ 正确触发 | 主动加载技能，并开始执行对应环节 |
| ⚠️ 触发但走错分支 | 触发了，但选错了入口（如该渲染却去调 OCR API） |
| ⚠️ 需人提醒才触发 | 首次无反应，用户点破后才加载技能 |
| ❌ 未触发 | 完全没意识到该用这个技能 |
| ❌ 误触发 | 无关请求却加载了技能 |

## A. 应当触发（10 例）

| # | 输入 | 期望走的环节 |
|---|---|---|
| A1 | 我有几份历年真题，帮我预测今年考点 | Skill B（预测） |
| A2 | 这份扫描版试卷能识别成 LaTeX 吗（附 PDF） | Skill A（渲染 + 识别） |
| A3 | 帮我把这堆试卷整理成能打印的样子（附多份 PDF） | Skill A → C → D |
| A4 | 用 exampaper 模板把我整理的题排版成 PDF | Skill C → D |
| A5 | 这道题今年会不会考 | Skill B（并说明需要历年卷） |
| A6 | 把这份期中卷的照片清理干净（附手拍图） | Skill A → C → D |
| A7 | 我们老师连着三年考同一道题，能分析出来吗 | Skill B |
| A8 | 帮我出一套模拟卷（附历年真题） | Skill B → C → D |
| A9 | 这个 PDF 里的公式能还原成 LaTeX 吗 | Skill A |
| A10 | 试卷里的电路图能重画一下吗（附图） | 图重绘（SVG） |

## B. 边界情况（5 例，可接受"先澄清"）

| # | 输入 | 合理反应 |
|---|---|---|
| B1 | 帮我复习信号与系统 | 先问"有真题/课件吗"，有则触发，无则给通用建议 |
| B2 | 这份 PDF 转成 Word | **不触发**（不是本技能职责），或明确说明不支持 |
| B3 | 帮我看看这份试卷（附 PDF，无其他说明） | 先澄清意图（整理？预测？识别？），不擅自开跑 |
| B4 | 期末快到了好焦虑 | **不触发**（情绪倾诉，非任务） |
| B5 | 帮我总结这份 PPT（附课件，无真题） | 触发 `ppt_only` 分支 → 应说明"仅课件模式未实现，需要试卷" |

## C. 不应触发（5 例，误触发即扣分）

| # | 输入 |
|---|---|
| C1 | 帮我写个 Python 脚本处理 CSV |
| C2 | 今天天气怎么样 |
| C3 | 解释一下傅里叶变换（纯知识问答） |
| C4 | 帮我订张火车票 |
| C5 | 这段代码有什么 bug（附 .py 文件） |

## D. 触发后的行为检查（针对命中的用例）

- [ ] 是否**先说明计划**再动手（而不是闷头跑）
- [ ] 是否**选对入口**（渲染→识别，而非直接调 OCR API）
- [ ] 是否**在关键节点停下来**让用户确认（如识别置信度低的题）
- [ ] 是否**说明了产出位置**
- [ ] 是否**报告了消耗**（读了几页、大致花了多少上下文）

## 记录方式

在 `benchmark/results-<agent>.csv` 的 `trigger_cases` 列写命中情况，例如：

```
A1✅ A2✅ A3⚠️走错分支 A4✅ A5✅ A6❌ A7✅ A8✅ A9✅ A10⚠️需提醒
B1✅ B2✅ B3⚠️擅自开跑 B4✅ B5✅
C1✅ C2✅ C3✅ C4✅ C5✅
```

格式：`用例号 + 结果符号`，空格分隔。`✅` 正确、`⚠️` 有瑕疵、`❌` 失败。
