## 一、必考点（6 份卷子里出现 5 次以上）

这 4 类**每份卷子都有**，且分值占比最高，属于「不复习就必丢分」的部分：

### 1. 数制与编码转换 ★★★★★

**6/6 出现**。几乎固定放在第一大题填空的前几空。

- 十进制 ↔ 二进制 / 八进制 / 十六进制（含小数部分，会规定误差，如「误差 < 1%」）
- **8421BCD 码**（5/6 出现）与 **余 3 BCD 码**
- 其他进制之间的直接转换（如十六进制 → 八进制）

> 例题（2018-19）：「将十进制数 46.75 分别转换成二进制数、十六进制数和 8421BCD 码」

### 2. 逻辑函数的化简与标准形式 ★★★★★

**6/6 出现**，且**至少占一道大题**。

- **卡诺图化简**（含带无关项 `∑d(...)` 的情形）→ 最简「与-或」式
- **最小项表达式** `∑m(...)` 与 **最大项表达式** `∏M(...)` 的互转
- 用**与非门 / 或非门**实现化简后的表达式（要画电路图）

> 例题（2012-13）：「化简逻辑函数 $F=\bar{A}BC+A\bar{B}C+AB\bar{C}+ABC$，写出最简与或式、最简或与式，并写出最小项表达式和最大项表达式」

### 3. 组合逻辑电路分析 ★★★★★

**6/6 出现**。给一张门电路图，要求：

1. 写出输出函数的**逻辑表达式**
2. 列出**真值表**
3. **说明该电路的功能**（这一步最容易丢分，必须能说出"这是全加器/比较器/译码器"）

### 4. 对偶函数与反函数 ★★★★☆

**5/6 出现**。填空常客。

- 已知 $F$，求**对偶函数** $F^*$ 与**反函数** $\bar{F}$
- 记住规则：对偶 = 与↔或、0↔1（变量不变）；反函数 = 与↔或、0↔1 **且变量取反**

## 二、着重复习（出现 3~4 次，属于「大概率考」

### 5. 险象（冒险）分析 ★★★★☆

**5/6 出现**，且**通常是一道 15 分的大题**。这是本课程**最有辨识度的考点**，务必吃透：

| 要会判断 | 要会做 |
|---|---|
| **功能险象**：输入信号变化时，输出是否出现不应有的尖峰 | 给定两个输入状态变化（如 `0111→1110`），判断是否产生险象 |
| **逻辑险象**：由电路结构决定 | 判断是 **0 冒险** 还是 **1 冒险** |
| | **消除方法**：① 加冗余项（卡诺图上补覆盖圈）② 加选通脉冲 ③ 加滤波电容 |

> 这是**唯一需要动手画仿真波形**的题型，复习时一定要练几道。

### 6. 数据选择器 74151 实现逻辑函数 ★★★★☆

**4/6 出现**。标准套路题：

- 用**一片** 74151 + 少量门电路实现 $F(A,B,C,D)=\sum m(\cdots)$
- 进阶：**降维卡诺图法**（地址端接三个变量，数据端接第四个变量的组合）
- 变体：用**两片** 74151 实现
- 也可能用 **8 选 1 数据选择器构造全加器** / **四选一构造全加器**

### 7. 全加器 74283 的应用 ★★★★☆

**4/6 出现**。几乎固定是「**用 74283 + 门电路设计 BCD 加法器**」：

- **余三 BCD 码全加器**（2012-13）：余三码 = 8421BCD + 0011
- **两位十进制（BCD）全加器**（2016-17）
- **四位十二进制全加器**（2017-18）
- **两位二进制加法器并显示和**（2006）

> 关键：记住「和为 10~15 时要加 6 修正」这个套路。

### 8. 原码 / 补码 / 溢出判断 ★★★★☆

**4/6 出现**。

- 原码 → 反码 → 补码的换算（含负数）
- **补码减法**：$A-B = A + [-B]_{补}$
- **溢出判断**（判断补码减法是否溢出）
- $n$ 位补码能表示的数值范围

### 9. 波形图 → 门电路设计 ★★★☆☆

**3/6 出现**。给一张输入 A、B、C、D 与输出 F 的波形图，要求：

- 从波形**推出真值表**
- 画**卡诺图**化简
- 用**与非门**实现（注意"只有原变量输入"的限制条件）

### 10. 译码器 74138 的应用 ★★★☆☆

**3/6 出现**。

- **3-8 线译码器实现多输出函数**（低电平输出，注意取反）
- **两片 2-4 线译码器扩展为 4-16 线译码器**

## 五、复习顺序建议

**第一优先（占分最多、必考）**

1. **卡诺图化简**（含无关项）→ 练到能在 3 分钟内出最简式
2. **组合逻辑电路分析**（表达式 → 真值表 → 说功能）
3. **数制与 BCD 码转换**（送分题，不能丢）

**第二优先（大题分量重）**

4. **险象分析**（判断 + 消除，一定要练波形图）
5. **74151 实现函数**（含降维卡诺图法）
6. **74283 设计 BCD 加法器**（记住 +6 修正）

**第三优先（填空常客）**

7. 对偶函数 / 反函数
8. 原码 / 补码 / 溢出判断

**考前速记**

- 与非表达式：先化简为与或式，再两次取反
- 74151 地址线 3 位、74138 位 3 线-8 线、74283 是 4 位超前进位全加器
- 险象消除的三种方法（加冗余项 / 选通脉冲 / 滤波电容）
