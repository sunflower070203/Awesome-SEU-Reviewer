# 考点归并规范（Skill B 第二步）

统计聚类（`predictor.py`）只能把**几乎相同的题**聚在一起。但真实试卷里，
**同一个考点的题常常措辞差异很大**，例如：

- 2023-24 第 3 题：`设 z = arctan(xy + sin(x+y))，求 dz|_{(0,π)}`（复合函数全微分）
- 2024-25 第 3 题：`f(x,x³)=x⁶+2x⁴, f_x(x,x³)=2x³-3x²，求 f_y(x,x³)`（隐式偏导）

两者字符重叠很低，但**考的是同一个知识点**。这一步交给你（Agent，具备语义理解）来完成。

## 输入

`predictor.py` 的输出（候选簇）：

```json
{
  "n_exams": 2,
  "exam_ids": ["2023-24", "2024-25"],
  "predictions": [
    {"rank": 1, "score": 1.0, "type": "fill", "positions": {"fill#1": 2},
     "stem_samples": ["直线 ... 垂直，求 λ", "直线 ... 与 ... 的夹角"]}
  ]
}
```

**同时请阅读原始的题目列表**（`pool.json` 的 `exams[].questions[]`），
候选簇只是线索，题目的完整题干在那里。

## 任务

把跨卷的题目**按「考点」重新分组**，输出 `topics.json`。

## 判断「同一考点」的准则

**算同一考点**（应合并）：

- 考查同一数学概念、同一类解题方法
  - 「求切平面」与「求切线」→ 同属**空间曲面/曲线的切对象**
  - 「质心」与「转动惯量」→ 同属**重积分的物理应用**
  - 「路径无关求 a」与「全微分求原函数」→ 同属**微分形式与路径无关**
- 只是数值、函数、参数不同（换数字不换套路）

**不算同一考点**（不合并）：

- 只是题号相同但内容无关（第 5 题这次考形心、下次考曲线积分，不能因题号相同就合并）
- 同属一大类但方法明显不同
  - 「幂级数求收敛域」与「幂级数求和函数」——**若两卷都只考其中一种，可合并**；
    若两卷分别考了两种，**视为两个考点**（都要复习）

**拿不准时**：拆开（宁可多列一个考点，不要漏掉）。

## 输出格式（严格 JSON）

```json
{
  "topics": [
    {
      "label": "绝对值函数的二重积分",
      "members": [
        {"exam": "2023-24", "number": 4, "type": "fill"},
        {"exam": "2024-25", "number": 4, "type": "fill"}
      ],
      "rationale": "两年都在第 4 题考绝对值函数的二重积分，仅被积函数由 |y-√x| 变为 |x+y|"
    }
  ]
}
```

字段说明：

| 字段 | 要求 |
|---|---|
| `label` | 考点名，**简洁具体**（「绝对值二重积分」优于「二重积分」；「空间曲线切线」优于「微分学」） |
| `members` | 该考点在各卷中的**每一道**对应题；`exam`/`number`/`type` 必须能在原始数据里找到 |
| `rationale` | 一句话说明判定依据，会直接展示给学生 |

## 完成后

1. 把结果写入 `topics.json`
2. 运行 `python scripts/predict/predictor.py --input pool.json --merge topics.json --format text`
3. **把完整考点清单呈现给用户**，并标注每个考点覆盖了几份卷子

## 不做的事

- 不编造成员（`members` 必须来自原始数据）
- 不遗漏题目（每道题至少属于一个考点）
- 不给考点打「会考/不会考」的标签——那是下一步（生成样卷）的决策
